# TableOps.jl

Fast, tidyverse-style table verbs for any [Tables.jl](https://github.com/JuliaData/Tables.jl)
table, in pure Julia with Tables.jl as the only dependency.

!!! warning "In development"
    TableOps is being built. Nothing is exported yet; the planned API is in the
    [Design](design.md) page.
