TableOps.Table — Type
Table(x)
Table(; name = column, ...)

A table with named columns. Table(x) accepts any Tables.jl table, and Table(; a = [1, 2], b = ["x", "y"]) builds one from keyword columns, in keyword order.

Columns are shared, not copied: Table(x) keeps the source's column vectors as they are, so changing a vector in place changes every table that holds it. A column that is not an AbstractVector is collected into one. A Table passed to Table is returned as is.

t.revenue returns the stored column, whatever the column is called, and throws an ArgumentError with a suggestion for an unknown name. A Table cannot be changed in place: t.revenue = v throws. names(t) returns the column names as a Vector{Symbol} (a copy). copy(t) copies every column with copy, so the result is independent of t except for the elements themselves: a column of vectors shares its inner vectors. isequal compares names and columns with isequal; == follows Julia's three-valued rule and can return missing.

Every column must use 1-based indexing, all names must be unique, and all columns must have the same length; otherwise an ArgumentError says how to fix it.

Examples

julia> using TableOps

julia> Table(; a = [1, 2], b = ["x", "y"])
2×2 Table
     a  b
 Int64  String
 ─────────────
     1  x
     2  y

A Table prints its size, the column names and types and the first and last rows, fitted to the display; glimpse shows one line per column. In the REPL, rows and columns are fitted to the screen; written elsewhere, all rows and columns are shown.

TableOps.as_table — Function
as_table(x)

Convert x to a Table: a Table is returned as is, and any other Tables.jl table is wrapped as in Table(x).

Examples

julia> using TableOps

julia> as_table((a = [1, 2],)) isa Table
true

julia> t = Table(; a = [1]); as_table(t) === t
true

TableOps.nrow — Function
nrow(t::Table)

The number of rows of t. A table with no columns has no rows.

Examples

julia> nrow(Table(; a = [1, 2, 3]))

TableOps.glimpse — Function
glimpse(x)
glimpse(io::IO, x)

Print a compact overview of the table x, any Tables.jl table: the size, then one line per column with its name, its element type and its first values, as many as fit in the width of io (the terminal for glimpse(x)). Returns nothing. Names, types and values wider than 20 columns are cut with …, and Union{Missing,T} is shown as T?.

Examples

julia> using TableOps

julia> glimpse(Table(; a = [1, 2, 3], b = ["x", "y", "z"]))
3×2 Table
 a  Int64   1, 2, 3
 b  String  x, y, z
